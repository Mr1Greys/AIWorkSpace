# Каталог специалистов — Спецификация

## Обзор

**Единая страница-каталог** `/freelancers` для поиска и фильтрации фрилансеров и команд.  
Главная страница направляет сюда через **пресеты** (категории/теги).  
Все фильтры работают через **query-параметры** → шарятся ссылкой, сохраняются при возврате.

---

## 🎯 Цели

- **Простота**: минимум фильтров, всё по делу
- **Гибкость**: один маршрут, разные пресеты
- **Шаринг**: любой набор фильтров = уникальная ссылка
- **СНГ-контекст**: часовые пояса, города, русский язык
- **AI-релевантность**: семантический поиск по умолчанию

## 🧱 Сайдбар фильтров

### 1. Направление (radio/чипы, пресеты)
```
🤖 AI
🌐 Веб-разработка  
📱 Telegram-боты
🎨 Дизайн
📊 Data/Аналитика
🔧 Все направления (дефолт)
```

**Логика:**
- Клик по направлению → автоматически проставляет базовые теги
- Примеры:
  - **AI** → `#Python`, `#LangChain`, `#LLM`, `#RAG`, `#OpenAI`
  - **Веб** → `#NextJS`, `#React`, `#TypeScript`, `#TailwindCSS`
  - **Telegram** → `#Python`, `#aiogram`, `#Telegram Bot API`, `#Node.js`
  - **Дизайн** → `#Figma`, `#UI/UX`, `#Prototyping`, `#Design Systems`
  - **Data** → `#Python`, `#Pandas`, `#SQL`, `#Jupyter`, `#Visualization`

### 2. Навыки (autocomplete + чипы)
```
Добавьте навык или тег…
```
- Autocomplete с подсказками: `#NextJS`, `#Python`, `#Figma`, `#Docker`, `#PostgreSQL`
- Выбранные навыки отображаются чипами
- **Это и есть "язык разработки"** — отдельный блок не нужен

### 3. Статус (toggle)
```
🟢 Доступен к сотрудничеству
🟡 В команде
⚪ Показать всех
```
- **По умолчанию**: показываем только 🟢 + 🟡 (активных)
- Чекбокс **"Показать неактивных"** → включает всех

### 4. Тип профиля (checkbox)
```
☐ Фрилансер
☐ Команда
```

### 5. Часовой пояс / Город (dropdown)
```
Часовой пояс / Город
```
**Опции:**
- СНГ (RU, KZ, UA, BY, AM, KG, UZ)
- Москва • Санкт-Петербург • Алматы • Минск • Тбилиси • Ереван • Бишкек • Ташкент

**Логика:**
- Если не выбрано → не фильтруем
- Полезно для созвонов в удобное время

### 6. Надёжность (checkbox)
```
☐ ✅ Верифицирован
☐ 🧾 Есть кейсы (≥1)
☐ ⭐ Рейтинг 4.5+
```

### 7. Сортировка (внизу сайдбара)
```
Сортировать:
• По релевантности (AI) — дефолт
• По рейтингу
• По активности (онлайн/недавно)
```

### Кнопки сайдбара
- **Сбросить фильтры** — видна только при наличии выбранных фильтров
- ~~Применить~~ — не нужна, фильтры работают реактивно

---

## 🔗 Примеры URL (query-параметры)

```
/freelancers?category=ai&skills=python,langchain&status=available&verified=1

/freelancers?category=web&skills=nextjs,typescript&profileType=team

/freelancers?search=telegram&status=team&rating=4.5

/freelancers?category=design&city=moscow&hasPortfolio=1
```

**Параметры:**
- `category` — направление (ai, web, telegram, design, data)
- `search` — текстовый поиск
- `skills` — навыки через запятую
- `status` — available, team, all
- `profileType` — freelancer, team
- `city` — город/часовой пояс
- `verified` — 1/0
- `hasPortfolio` — 1/0
- `rating` — минимальный рейтинг (4.5)
- `sort` — relevance, rating, activity

## 🧠 Логика выдачи

### Релевантность (AI)
- Семантический матч запроса/направления с навыками профиля
- Используем эмбеддинги (OpenAI/Cohere)
- Ранжирование по косинусному сходству

### Жёсткие фильтры
- Статус (available, team)
- Тип профиля (freelancer, team)
- Верификация
- Наличие кейсов
- Рейтинг

### Сортировка
- **По релевантности** — AI-скор + рейтинг
- **По рейтингу** — убывание
- **По активности** — онлайн → недавно → давно

---

## 🗂️ Пустая выдача

### Что показываем
```
Ничего не найдено. Попробуйте убрать часть фильтров.
```

### Действия
1. **3–5 ближайших совпадений** (AI-релакс фильтра)
2. Кнопка **"Сбросить фильтры"**
3. Призыв: *"Не нашли нужного специалиста? [Создайте запрос](#) — мы уведомим подходящих фрилансеров"*

### Цвета статусов
- 🟢 **Доступен** — `bg-green-100 text-green-700`

- Зелёная точка в правом верхнем углу аватара
- Пульсирующая анимация

### Чипы навыков
- Фон: `bg-primary-50 text-primary-700`
- Hover: `bg-primary-100`
- Выбранный: `bg-primary-600 text-white`

### Анимации
- Hover карточки: `scale(1.02)` + тень
- Появление фильтров: `fade-in` 200ms
- Смена выдачи: `fade` 150ms

## 🧩 Почему это правильно

### ✅ Простота
- 6 блоков фильтров, всё по делу
- Нет "язык общения", "опыт", "CMS" и прочего мусора

### ✅ Язык разработки встроен в Навыки
- Не плодим дубли
- `#Python`, `#Go`, `#TypeScript` — это теги-навыки

### ✅ СНГ-контекст
- Часовой пояс/город вместо странного "локейшна"
- Удобно для созвонов

### ✅ Единый маршрут
- Одна страница — разные пресеты
- Чисто и масштабируемо

### ✅ Шаринг
- Любой набор фильтров = уникальная ссылка
- Можно сохранить, отправить коллеге

### ✅ AI-релевантность
- Семантический поиск по умолчанию
- Умный fallback при пустой выдаче

## 🛠️ Технические детали

### Стек
- **Frontend:** Next.js 14 (App Router), React, TypeScript
- **Styling:** TailwindCSS
- **State:** URL Search Params (nuqs)
- **Search:** OpenAI Embeddings / Algolia
- **Backend:** tRPC / REST API

### API Endpoints
```typescript
GET /api/freelancers
  ?search=string
  &category=ai|web|telegram|design|data
  &skills=python,langchain
  &status=available|team|all
  &profileType=freelancer|team
  &city=moscow
  &verified=1
  &hasPortfolio=1
  &rating=4.5
  &sort=relevance|rating|activity
  &page=1
  &limit=20
```

### Database Schema
```sql
-- Таблица freelancers
id, name, avatar, headline, bio, 
rating, reviews_count, experience,
location, timezone, status, 
profile_type, verified, online,
created_at, updated_at

-- Таблица skills (many-to-many)
id, freelancer_id, skill_name, skill_category

-- Таблица portfolio_cases
id, freelancer_id, title, description, 
image_url, tags, created_at
```
