## 🚀 Как использовать

### Вход через веб-интерфейс:

1. Откройте http://localhost:3000/auth/signin
2. Выберите нужный тестовый аккаунт из списка
3. Скопируйте email и пароль
4. Нажмите "Войти"

### Быстрый вход (для разработки):

Тестовые данные отображаются прямо на странице входа в специальном блоке с пунктирной рамкой.

## 🎯 Сценарии тестирования

### Сценарий 1: Создание проекта
1. Войти как **Заказчик**
2. Перейти в `/brief`
3. Создать новый проект
4. Просмотреть AI-подбор специалистов

### Сценарий 2: Отклик на проект
1. Войти как **Фрилансер**
2. Перейти в `/projects`
3. Выбрать проект
4. Откликнуться на задание

### Сценарий 3: Создание сделки
1. Войти как **Заказчик**
2. Выбрать исполнителя
3. Создать эскроу-сделку
4. Внести средства

### Сценарий 4: Разрешение спора
1. Войти как **Админ**
2. Перейти в `/admin/disputes`
3. Просмотреть активные споры
4. Принять решение
