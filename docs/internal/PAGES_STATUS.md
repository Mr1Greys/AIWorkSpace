## ❌ Отсутствующие критичные страницы

### 1. Авторизация и регистрация

#### `/auth/signin` - Страница входа
**Приоритет:** 🔴 Критично  
**Описание:** Вход через GitHub, LinkedIn, Telegram, Email или Web3 кошелёк

**Требуемые элементы:**
- Заголовок "Войти в AIWorkSpace"
- Кнопки OAuth (GitHub, LinkedIn, Telegram)
- Разделитель "или"
- Форма Email + Пароль
- Кнопка "Войти через кошелёк" (SIWE)
- Ссылка "Забыли пароль?"
- Ссылка "Нет аккаунта? Зарегистрироваться"

#### `/auth/signup` - Страница регистрации
**Приоритет:** 🔴 Критично  
**Описание:** Регистрация с выбором роли (заказчик/исполнитель)

**Требуемые элементы:**
- Заголовок "Создать аккаунт"
- Выбор роли: "Я ищу специалистов" / "Я специалист"
- Кнопки OAuth
- Форма: Имя, Email, Пароль, Telegram (опционально)
- Для исполнителей: выбор навыков с AI-подсказками
- Чекбокс согласия с условиями
- Кнопка "Создать аккаунт"
- Ссылка "Уже есть аккаунт? Войти"

#### `/auth/callback` - OAuth callback
**Приоритет:** 🔴 Критично  
**Описание:** Обработка OAuth редиректов

---

### 2. Команды

#### `/teams` - Каталог команд
**Приоритет:** 🟡 Средний  
**Описание:** Список студий и коллективов специалистов

**Требуемые элементы:**
- Заголовок "Команды специалистов"
- Поиск по названию/навыкам
- Фильтры:
  - Направление (Веб, Мобильная, AI, Web3)
  - Размер команды (2-5, 6-10, 10+)
  - Средний рейтинг
  - Средняя ставка
- Сортировка: по рейтингу, проектам, новизне
- Карточки команд:
  - Название и логотип
  - Количество участников
  - Специализация
  - Теги навыков
  - Рейтинг и количество проектов
  - Кнопки: "Подробнее", "Пригласить"

#### `/teams/[id]` - Детали команды
**Приоритет:** 🟡 Средний  
**Описание:** Подробная информация о команде

**Требуемые элементы:**
- Название, описание, специализация
- Список участников с ролями и фото
- Портфолио команды (кейсы)
- Статистика: проектов завершено, средний рейтинг
- Отзывы клиентов
- Кнопка "Отправить заказ"

---

### 3. Кейсы (портфолио)

#### `/cases` - Список кейсов
**Приоритет:** 🟡 Средний  
**Описание:** Галерея выполненных работ

**Требуемые элементы:**
- Заголовок "Портфолио специалистов"
- Фильтры:
  - Категория (Веб, AI, Дизайн, Web3)
  - Технологии (теги)
  - Бюджет
- Сортировка: новые, популярные, по бюджету
- Карточки кейсов:
  - Превью изображение
  - Название проекта
  - Теги технологий
  - Бюджет и сроки
  - Автор (ссылка на профиль)
  - Кнопка "Подробнее"

#### `/cases/[id]` - Детали кейса
**Приоритет:** 🔴 Критично  
**Описание:** Подробное описание выполненной работы

**Требуемые элементы:**
- Название и автор
- Главное изображение/видео
- Подробное описание
- Стек технологий (теги)
- Галерея изображений (3-6 шт)
- Результаты и метрики
- Отзыв заказчика (если есть)
- Кнопки: "Связаться", "Пригласить", "Поделиться"
- Похожие кейсы

### 4. Статические страницы

#### `/about` - О платформе
**Приоритет:** 🟢 Низкий  
**Описание:** Информация о проекте, миссия, команда

**Требуемые элементы:**
- Hero: "О платформе AIWorkSpace"
- Миссия и ценности
- Как это работает (3-4 шага)
- Преимущества для заказчиков
- Преимущества для исполнителей
- Статистика (пользователи, проекты, сделки)
- Команда проекта (опционально)
- CTA: "Присоединиться"

#### `/help` - Центр помощи
**Приоритет:** 🟢 Низкий  
**Описание:** FAQ и инструкции

**Требуемые элементы:**
- Поиск по вопросам
- Категории:
  - Начало работы
  - Для заказчиков
  - Для исполнителей
  - Оплата и эскроу
  - Безопасность
  - Споры
- FAQ аккордеон
- Контакты поддержки
- Ссылки на документацию

#### `/privacy` - Политика конфиденциальности
**Приоритет:** 🟢 Низкий  
**Описание:** Юридический документ

**Требуемые элементы:**
- Заголовок и дата последнего обновления
- Оглавление с якорями
- Разделы:
  - Сбор данных
  - Использование данных
  - Хранение и защита
  - Права пользователей
  - Cookies
  - Контакты

#### `/terms` - Условия использования
**Приоритет:** 🟢 Низкий  
**Описание:** Пользовательское соглашение

**Требуемые элементы:**
- Заголовок и дата
- Оглавление
- Разделы:
  - Общие положения
  - Права и обязанности
  - Оплата и возвраты
  - Ответственность
  - Разрешение споров
  - Изменения условий

### 5. Админ-панель

#### `/admin` - Главная админки
**Приоритет:** 🟡 Средний  
**Описание:** Управление платформой

**Требуемые элементы:**
- Дашборд с метриками:
  - Активные пользователи
  - Новые регистрации
  - Активные проекты
  - Объём эскроу-транзакций
  - Средний чек
- Быстрые действия
- Последние события

#### `/admin/users` - Управление пользователями
**Приоритет:** 🟡 Средний  
**Требуемые элементы:**
- Таблица пользователей
- Фильтры: роль, статус, дата регистрации
- Поиск по email/имени
- Действия: просмотр, блокировка, удаление

#### `/admin/disputes` - Споры
**Приоритет:** 🔴 Критично  
**Требуемые элементы:**
- Список споров
- Фильтры: статус, сумма, дата
- Детали спора:
  - Участники
  - Описание
  - История сообщений
  - AI-рекомендация
  - Ползунок распределения средств
  - Кнопка "Применить решение"

#### `/admin/moderation` - Модерация контента
**Приоритет:** 🟡 Средний  
**Требуемые элементы:**
- Очередь на модерацию:
  - Кейсы
  - Профили
  - Проекты
- Действия: одобрить, отклонить, запросить правки
