# 👨‍💻 Freelancer Components

Компоненты, специфичные только для исполнителей.

## 📁 Структура

```
freelancer/
├── BidsList.tsx           # Список откликов исполнителя
├── PortfolioGrid.tsx      # Сетка портфолио
├── FreelancerStats.tsx    # Статистика для dashboard
└── ActiveOrders.tsx       # Текущие заказы (будет создан)
```

## 🎯 Использование

Эти компоненты используются только на страницах исполнителя:
- `/dashboard/(freelancer)/overview`
- `/dashboard/(freelancer)/my-bids`
- `/dashboard/(freelancer)/portfolio`

## 📝 Примечание

Для общих компонентов используйте `/components/shared/`
