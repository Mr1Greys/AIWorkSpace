# 👨‍💻 Dashboard - Исполнитель

Страницы личного кабинета для роли **Freelancer** (исполнитель).

## 📁 Структура

```
(freelancer)/
├── overview/           # Главная страница dashboard исполнителя
│   └── page.tsx       # /dashboard/overview (только для freelancer)
│
├── my-bids/           # Мои отклики на проекты
│   └── page.tsx       # /dashboard/my-bids
│
├── my-projects/       # Мои текущие заказы
│   └── page.tsx       # /dashboard/my-projects (будет создан)
│
└── portfolio/         # Портфолио исполнителя
    ├── page.tsx       # /dashboard/portfolio - список кейсов
    └── new/
        └── page.tsx   # /dashboard/portfolio/new - добавить кейс
```

## 🎯 Функционал

### Overview (Главная)
- Быстрая статистика (заработок, проекты, рейтинг)
- Текущие активные заказы
- Последние события и уведомления
- Следующие действия (призывы к действию)

### My Bids (Мои отклики)
- Список всех откликов на проекты
- Фильтры по статусу (pending, accepted, rejected)
- Отслеживание статуса каждого отклика

### My Projects (Мои заказы)
- Текущие активные заказы
- Архив завершённых проектов
- Детали по каждому заказу

### Portfolio (Портфолио)
- Список всех кейсов
- Добавление нового кейса
- Редактирование существующих кейсов

## 🔒 Доступ

Все страницы в этой папке доступны только для пользователей с ролью `freelancer`.
Route group `(freelancer)` не влияет на URL - маршруты остаются как `/dashboard/overview`.

## 🚦 Редирект

При попытке доступа с ролью `client` пользователь будет перенаправлен на соответствующую страницу заказчика.
