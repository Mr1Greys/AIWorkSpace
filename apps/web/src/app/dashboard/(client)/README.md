# 💼 Dashboard - Заказчик

Страницы личного кабинета для роли **Client** (заказчик).

## 📁 Структура

```
(client)/
├── overview/                # Главная страница dashboard заказчика
│   └── page.tsx            # /dashboard/overview (только для client)
│
├── my-projects/            # Размещённые проекты
│   ├── page.tsx            # /dashboard/my-projects - список
│   └── new/
│       └── page.tsx        # /dashboard/my-projects/new - создать проект
│
└── hired-freelancers/      # Нанятые исполнители
    └── page.tsx            # /dashboard/hired-freelancers
```

## 🎯 Функционал

### Overview (Главная)
- Быстрая статистика (проекты, бюджет, исполнители)
- Размещённые проекты с откликами
- Активные исполнители в работе
- Последние события и уведомления

### My Projects (Мои проекты)
- Список всех размещённых проектов
- Фильтры по статусу (draft, active, in-progress, completed)
- Просмотр откликов на каждый проект
- Создание нового проекта

### Hired Freelancers (Нанятые исполнители)
- Список всех исполнителей, с которыми работали
- Фильтр по статусу (активные, завершённые)
- Статистика по каждому исполнителю
- Быстрый доступ к чату и профилю

## 🔒 Доступ

Все страницы в этой папке доступны только для пользователей с ролью `client`.
Route group `(client)` не влияет на URL - маршруты остаются как `/dashboard/overview`.

## 🚦 Редирект

При попытке доступа с ролью `freelancer` пользователь будет перенаправлен на соответствующую страницу исполнителя.

## 📝 Примечание

Ранее папка называлась `/dashboard/freelancers/`, что вводило в заблуждение.
Новое название `hired-freelancers` более точно описывает функционал.
