# 🔄 Dashboard - Shared (Общие страницы)

Страницы личного кабинета, **доступные для обеих ролей** (freelancer и client).

## 📁 Структура

```
(shared)/
├── settings/          # Настройки профиля
│   └── page.tsx      # /dashboard/settings - настройки для обеих ролей
│
├── messages/         # Сообщения и чаты
│   └── page.tsx      # /dashboard/messages
│
├── finances/         # Финансы и транзакции
│   └── page.tsx      # /dashboard/finances
│
├── balance/          # Баланс и кошелёк
│   └── page.tsx      # /dashboard/balance
│
├── reviews/          # Отзывы (даю и получаю)
│   └── page.tsx      # /dashboard/reviews
│
└── teams/            # Команды
    └── page.tsx      # /dashboard/teams
```

## 🎯 Функционал

### Settings (Настройки)
- **Freelancer**: Профиль исполнителя (навыки, портфолио, ставка)
- **Client**: Профиль заказчика (компания, отрасль)
- Общие настройки: email, telegram, аватар, город

### Messages (Сообщения)
- Список всех чатов
- Быстрый доступ к активным диалогам
- Уведомления о новых сообщениях

### Finances (Финансы)
- История всех транзакций
- **Freelancer**: Заработок, выплаты, эскроу
- **Client**: Расходы, оплаты проектов

### Balance (Баланс)
- Текущий баланс
- Пополнение / вывод средств
- Связанные кошельки (TON, USDT)

### Reviews (Отзывы)
- **Freelancer**: Полученные отзывы от заказчиков
- **Client**: Полученные отзывы от исполнителей
- Средний рейтинг

### Teams (Команды)
- Список команд, в которых участвую
- Создание новой команды
- Управление участниками

## 🔒 Доступ

Все страницы в этой папке доступны для **обеих ролей** (freelancer и client).
UI адаптируется в зависимости от роли пользователя.

Route group `(shared)` не влияет на URL - маршруты остаются как `/dashboard/settings`.

## 💡 Адаптивность

Компоненты на этих страницах проверяют `currentRole` из `RoleContext` и адаптируют UI:
- Разные формы в настройках
- Разная статистика в финансах
- Разные действия в зависимости от роли
